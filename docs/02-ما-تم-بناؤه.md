# LIONX — ما تم بناؤه فعليًا

## الملخص

تم بناء نسخة Web وموبايل من قاعدة Expo/React Native واحدة، مع هوية RTL Black & Gold، كتالوج رقمي، تنقل بين القطاعات، سلة وطلبات محلية، دفع يدوي، صفحات محتوى، صفحات شركات، وفوتر اجتماعي. النسخة الحالية جاهزة للمعاينة والاختبار، وليست نظامًا ماليًا إنتاجيًا.

## الوظائف المنفذة

| المجال | ما تم بناؤه | الحالة الحالية |
|---|---|---|
| الصفحة الرئيسية | شعار LIONX، قطاعات المول، الخدمات المختارة، البحث، الفوتر | يعمل على Web والموبايل |
| كتالوج الخدمات | بيانات خدمات مشتركة، تصنيفات، قطاعات PLAY/PAY/GROW/DIGITAL/VIP، تفاصيل خدمة | يعمل محليًا من `shared/catalog.ts` |
| السلة | إضافة الخدمات ومراجعة العناصر والإجمالي | محلية على الجهاز |
| Checkout | مراجعة الطلب والتحويل إلى الدفع اليدوي أو شحن الرصيد | يعمل دون دفع آلي |
| دفع قيمة الطلب | يأخذ المبلغ من إجمالي السلة | حالة `pending_review` بعد الإرسال |
| شحن الرصيد | العميل يحدد المبلغ ضمن الحدود المعروضة | لا تتم إضافة الرصيد تلقائيًا |
| وسائل الدفع اليدية | Vodafone Cash `01055861819`، Orange Money `01233309491`، InstaPay `maxabx3@instapay` مع زر نسخ | تعمل في صفحة `/payment-methods` |
| إثبات الدفع | اختيار صورة أو PDF للإيصال، مع رقم محفظة العميل | محلي للمعاينة، وليس تخزينًا خادميًا |
| تأكيد الطلب | رقم طلب، نوع العملية، المبلغ، بيانات المطابقة، وزر WhatsApp | يعمل مع الرقم الدولي `201279332563` |
| تتبع الطلب | عرض حالات الطلب وسجل الأحداث المحلي | تجريبي محلي |
| المحفظة | رصيد تجريبي وزر إضافة رصيد | لا تمثل رصيدًا ماليًا حقيقيًا |
| الشركات | Corporate وQuote Builder لطلب نطاق وعرض سعر | محلي للمراجعة |
| المحتوى | About، FAQ، Contact، Terms، Privacy، Blog، Academy، Tools، Offers، Affiliate، Courses | صفحات تمهيدية قابلة للتوسعة |
| الإدارة | Suppliers، Pricing، Analytics، Content، Users، Tickets، Coupons، Operations | Placeholder فقط، بلا RBAC فعلي |
| LionxPay | Cards، KYC، Charge، Withdraw | Placeholder فقط، غير مفعّل |
| السوشيال | Facebook، Instagram، TikTok، Threads، Telegram، LinkedIn، WhatsApp بأصول PNG وروابط قابلة للضغط | يعمل في الفوتر |
| Web Hosting | GitHub Pages، Workflow تلقائي، base URL، مسارات نظيفة | منشور دائمًا |

## المسارات المهمة

المسار الدائم للموقع هو:

`https://lionxagancy-pixel.github.io/lionx-mobile-Public/`

صفحة الدفع اليدوي هي:

`https://lionxagancy-pixel.github.io/lionx-mobile-Public/payment-methods/`

صفحة شحن الرصيد تُفتح من المحفظة أو Checkout، وتستخدم نفس نموذج الدفع اليدوي مع `operation=wallet_topup`.

## الجودة والاختبار

تم تشغيل TypeScript وlint وVitest وExpo Web build بنجاح. آخر Workflow منشور نجح بعد رفع إصلاح المسارات الديناميكية، والـcommit المرجعي هو `14939e8`. يظل اختبار logout متروكًا عمدًا لأنه يحتاج إعداد مصادقة حقيقيًا.

## ما لم يُبنَ بعد

لم يُبنَ تخزين خادمي للإيصالات، ولا حسابات إنتاجية، ولا RBAC، ولا محرك تسعير supplier + markup + fee + tax، ولا تكامل مورد Gamsgo، ولا مزود دفع آلي، ولا LionxPay إنتاجي. هذه العناصر تحتاج قرارات تشغيلية وأمنية قبل كتابتها.
